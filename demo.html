Saneca TV — Example Page

This page represents any host site the widget gets embedded into.

This is a stand-in for a normal page on your site — its own fonts, its own layout, nothing to do with LangSync. The widget below is dropped in with a single script tag and floats independently in the corner.

Tap the bubbles in the bottom-right corner — the mic opens the live speech translator, and the "Aあ" bubble next to it opens a type-to-translate panel. Both can run on the same page at once without conflicting.
